AI-Powered Sales Data Analysis Dashboard

Project Overview

This beginner-friendly data analytics project explores sales data using Python. It summarizes sales and profit performance and visualizes trends to help understand business results.

Tools Used

- Python
- Pandas
- Plotly
- Google Colab

Dataset

This project uses a simulated sales dataset created for learning and demonstration. It does not contain real company or customer data.

Project Features

- Total sales and profit summary
- Order count and average order value
- Monthly sales trend visualization
- Sales comparison by region
- Sales distribution by category
- Top-selling product analysis
- Rule-based business insights

How to Run

1. Open the ".ipynb" notebook in Google Colab.
2. Run the notebook cells in order.
3. Explore the generated charts and summary metrics.
